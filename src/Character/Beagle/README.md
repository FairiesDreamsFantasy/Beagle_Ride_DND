# Beagle Subsystem

## Overview
Houses the four authentic rideable Giant Beagles in Beagle Ride DND. Each canine is engineered with distinct physical dimensions, coat colorations, accessories, vocalization acoustic frequencies, and stride dynamics.

## The Beagle Roster

### 1. Jetta (`JETTA`)
* **Shoulder Height**: 5 feet 2 inches
* **Dimensions**: 36" width, 7 ft length
* **Coat**: White with a red-orange saddle mark
* **Details**: Dark-blue eyes, red-orange nose, peach skin tone, blue collar with yellow circles.
* **Locomotion**: Standard calibrated stride, classic SM64-inspired low-poly 3D projection.

### 2. Elsa (`ELSA`)
* **Shoulder Height**: 5 feet 4 inches
* **Dimensions**: 36" width, 7 ft length
* **Coat**: Yellow with a dark-pink saddle mark
* **Details**: Indigo eyes, black nose, dense thick dark-yellow fur profile.
* **Locomotion**: Robust trot and heavy gallop cadence, unique deep harmonic baying.

### 3. Thelma (`THELMA`)
* **Shoulder Height**: 6 feet 0 inches
* **Dimensions**: 40" width, 8 ft length (head height 46", head width 36.5")
* **Coat**: Red with a white saddle mark
* **Details**: Light green eyes, dark-brown nose/ears/paw pads, white tail. Fur thickness factor 1.15. Majestic white mane (15" thick, 18" wide).
* **Accessories**: Tiara, Purple collar decorated with Yellow Diamonds.

### 4. Tina (`TINA`)
* **Shoulder Height**: 5 feet 0 inches
* **Dimensions**: 36" width, 6.5 ft length (head height 45", head width 34")
* **Coat**: Light-blue with a dark-pink circular saddle mark
* **Details**: Dark-green eyes, dark-pink nose, dark-blue ears with indigo tips, dark-pink paw pads. Upright tail with quarter-pipe curve.
* **Accessories**: Earrings, Green collar decorated with vertical orange ovals.
